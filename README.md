# Thread Theory — Demo Store

A responsive T-shirt storefront concept by Ribu Web Studio. Products, prices, business details, and the testimonial are demo content. Orders are prepared for WhatsApp; the demo does not collect payments.

## Run locally on Windows

Open this folder in VS Code, then run these commands in its PowerShell terminal:

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Configure WhatsApp before using for a real store

Set `STORE_WHATSAPP_NUMBER` near the top of `src/main.jsx` to the store owner's international number using digits only. Replace demo product details and placeholder contact information before launch.
